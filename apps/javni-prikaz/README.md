# Prometni utrip Tržiča — javni prikaz v1.6

Javna, poenostavljena aplikacija za prikaz prometa, hitrosti in zasedenosti spremljanih parkirišč. Vključena je v source package v1.9.1 in je v zaključku prve faze vsebinsko nespremenjena.

## Prikazi

- promet po izbranem obdobju;
- delavniki, vikendi in prazniki;
- smer V lokacijo / IZ lokacije;
- sestava vozil in povprečne hitrosti;
- sedem parkirišč in enoletni 3-urni profil.

## Omejitve

Meritve veljajo za konkretne senzorje in spremljane lokacije. Ocenjeni dnevi CABLEX so označeni. PISO prostorski izvozi so v prvi fazi samo dokumentacijski kontekst in niso dodani kot javne karte.
