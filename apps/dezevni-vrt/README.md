# Deževni vrt OŠ Bistrica v0.1

**Stanje:** Source package v1.9.1; podatkovni presek 27. 5.–23. 7. 2026.

Nova samostojna statična aplikacija platforme Utrip Tržiča.

## Datoteke
- `index.html` - uporabniški vmesnik
- `styles.css` - lastni slog aplikacije
- `app.js` - izračuni, tri ugotovitve in grafa
- `data-js/zentra-data.js` - dnevno agregirani podatki za lokalno delovanje
- `data-source/` - ohranjeni izvorni CSV izvozi in normalizirana datoteka

## Pomembne omejitve
- Obdobje meritev je 27. 5. 2026-23. 7. 2026.
- Padavinski podatki se med Tanki razlikujejo in niso uporabljeni kot skupna meteoroloska vsota.
- Tenziometri vsebujejo skrajne in nespremenjene vrednosti, zato niso uporabljeni v glavnih ugotovitvah.
- Opazene povezave niso dokaz vzroka in posledice.
