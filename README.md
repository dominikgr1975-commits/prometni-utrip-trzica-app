# Prometni utrip Tržiča v0.3

Statična spletna aplikacija za GitHub Pages. Ne potrebuje Node.js, React builda ali strežnika.

## Novosti v v0.3

- modra barvna shema iz prve različice,
- dodatni KPI: povprečna temperatura, število prebivalcev in povprečna hitrost CABLEX,
- nov scenarij: vpliv spremembe števila zaposlenih na zasedenost izbranega parkirišča,
- obstoječi podatki in modeli ostajajo nespremenjeni.

Podatek o številu prebivalcev v priloženih datotekah ni bil na voljo, zato kartica začasno prikaže pomišljaj. Ko bo podatek dodan, v `data/analysis.json` nastavi `kpis.population2025`.
