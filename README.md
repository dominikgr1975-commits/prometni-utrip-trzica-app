# Prometni utrip Tržiča v0.4

Statična spletna aplikacija za GitHub Pages.

## Novosti

- modra vizualna shema,
- KPI: temperatura, prebivalci in povprečna hitrost,
- scenarij vpliva zaposlenih na parkirišča,
- scenarij vpliva spremembe števila prebivalcev na promet in parkirišča.

## Objavljanje

Naloži vse datoteke in mapo `data` v koren izbranega GitHub brancha. GitHub Pages mora biti nastavljen na ta branch in mapo `/(root)`.
