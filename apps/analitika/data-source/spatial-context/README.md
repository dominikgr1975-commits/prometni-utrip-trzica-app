# Občinski prostorski in mobilnostni kontekst

## Objavljena agregata

1. `Naselja-po-KSjih-PP-2024.csv` — naselja, krajevne skupnosti, naslovne točke, geokode in agregati prijav prebivališča;
2. `Evidenca opremljenosti postajališč_201801.xlsx` — zgodovinski presek opremljenosti avtobusnih postajališč z dne 15. 1. 2018.

Izvorni datoteki nista vključeni v javni paket. Naslovni podatki so agregirani; evidenca postajališč se uporablja samo zgodovinsko. Objavni agregat je v `../../data-js/spatial-context.js`.

## PISO Desktop

Pregledani so bili atributni izvozi BCP, BUS, pločniki, omejitve hitrosti, naselja, hitrost, kolesarske poti in cestne zapore. Podrobna ocena je v `PISO_DESKTOP_IZVOZI.md`.

PISO izvozi v prvi fazi niso vključeni v javne izračune ali surove datoteke. Ne vplivajo na formule, uteži, indeks Utrip Tržiča, kakovost podatkov ali zanesljivost modela. Za prihodnje prostorske preseke so potrebni geometrijski izvozi in šifranti.
