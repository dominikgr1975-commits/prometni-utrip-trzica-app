# Uresničevanje Strategije turizma 2024–2031 v0.1

**Stanje:** Source package v1.9.1; turistični podatki januar 2018–junij 2026.

Samostojna statična aplikacija platforme Utrip Tržiča.

## Namen

Primerja merljive cilje Strategije razvoja turizma v Občini Tržič 2024-2031 z dejanskimi podatki aplikacije obveznega porocanja v turizmu.

## Obdobje podatkov

- celotno razpolozljivo obdobje: januar 2018-junij 2026;
- zadnje zaključeno leto za letne primerjave: 2025;
- leto 2026 se primerja samo za januar-junij z januarjem-junijem 2025.

## Pravila

- brez simulacij in napovedi;
- odstotek doseganja se računa samo za številčno dolocene cilje;
- kvalitativni cilji brez ustreznega kazalnika so označeni kot nemerljivi;
- OPN je prostorski kontekst in ni dokaz izvedbe strategije.

## Podatki

Aplikacija neposredno uporablja podatkovni datoteki iz `apps/turizem/data-js/`:

- `tourism-summary.js`;
- `tourism-accommodation.js`.

Ob prihodnji posodobitvi turističnih podatkov se zato primerjave osvežijo brez podvajanja podatkovnega sklopa.
